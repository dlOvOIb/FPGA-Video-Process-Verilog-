## 0 FPGA视频处理介绍
FPGA视频数据来源有很多，可以从摄像头、HDMI接口灯多种信号源接入，进入FPGA后都会被处理为dvi格式，即24位或16位的数据data，场同步信号vs，行同步信号hs以及有效信号de

由于原始视频数据为流式输入，我将FPGA的视频处理分为两类：线性和非线性。

线性是指输入一个像素，处理完后直接输出一个像素，通常是对视频进行颜色处理或是涉及到窗口扫描操作的处理。开发难度较低。

非线性则是类似对图像进行旋转、FFT等需要完整或大部分图像数据的操作，一般这类处理需要外接DDR3等器件来存储完整图像数据。开发难度爆炸。
